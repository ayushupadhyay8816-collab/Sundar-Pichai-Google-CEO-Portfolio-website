# Sundar Pichai Portfolio Website

A polished, responsive portfolio built with HTML5 and external CSS3. It includes a visual hero section, biography, education/career timeline, contribution cards, multi-photo gallery, references and student-details footer.

## Files
- `index.html` — page content and layout
- `style.css` — styling and responsive design
- `.nojekyll` — GitHub Pages helper

## Preview locally
Extract the ZIP and open `index.html` in a browser. An internet connection is needed for the online photos and Google Fonts.

## Publish on GitHub Pages
1. Upload `index.html`, `style.css`, and `.nojekyll` to the root of your GitHub repository.
2. Commit the changes to branch `main`.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then click **Save**.
5. Wait a few minutes for GitHub to publish the site.

Replace `[Your Name]` in the footer before submitting. Check photo licenses/attribution on Wikimedia Commons before public reuse.
